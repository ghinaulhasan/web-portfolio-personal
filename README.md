## Overview

The site is a front-end portfolio experience using a light visual theme, responsive Bootstrap layout, custom CSS, and JavaScript interactions.

## Highlights

- Personal introduction and portfolio presentation
- Services and project showcase sections
- Contact information and social-link area
- Responsive layout using Bootstrap
- Scroll and hover effects, with Animate.css and AOS assets included
- Dark-mode styling support in the page styles

## Built with

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Animate.css
- AOS
- Google Fonts (Poppins and Montserrat)

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ghinaulhasan/web-portfolio-personal.git
   cd web-portfolio-personal
   ```
2. Open `index.html` in your browser, or open the folder in VS Code and use a local development server.

No build step is required for this static front-end project. External CDN assets require an internet connection.

## Main files

- `index.html` — page structure and layout
- `style.css` — visual styling
- `scripte.js` — page interactions
- `assets/` — project assets
